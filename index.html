Run it with your data

  1. Get the pipeline folder, including the local pyMOU source.
  2. Install the Python dependencies and set the input paths in the notebook.
  3. Run the sections in order to fit the models, select τ and save the result.

The website displays the saved notebook; it does not execute the analysis. Input data are not included. The example uses HCP regional time series and a 100-to-62 cortical mapping.

The pipeline selects an interior local minimum of the correlation with a precision-based reference, within the retained convergent interval. The notebook shows the eligibility checks and diagnostics.
